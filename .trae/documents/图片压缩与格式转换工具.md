# 图片压缩与格式转换工具（纯前端）

## Summary

构建一个纯前端静态页面（HTML + CSS + JS，无后端、无构建工具），支持选择/拖拽多格式图片（webp/jpg/jpeg/png，含 >5MB 大图），通过浏览器 Canvas API 完成压缩（质量调节、尺寸缩放）与格式转换（jpg/png/webp 互转），并逐个下载处理结果。

## Current State Analysis

- 工作区无实际应用项目，`demo-showcase/` 是一个静态演示页（index.html + style.css + script.js 三文件结构，中文页面）。
- 本次为新增独立功能页面，不修改 `demo-showcase/`，遵循其"三文件、中文、原生 JS"的目录与代码风格。
- 用户上传的 8 张测试图位于 `/workspace/.uploads/`（3 张 webp、3 张 jpg/jpeg、1 张 >5MB 的 2480x3508 PNG、1 张 jpeg），覆盖多格式与大文件场景，可直接用于验证。

## Proposed Changes

新建目录 `/workspace/image-tool/`，共 3 个文件：

### 1. `image-tool/index.html`

- 页面结构（中文界面）：
  - 拖拽区 + "选择图片"按钮（`<input type="file" multiple accept="image/webp,image/jpeg,image/png">`）
  - 设置区：目标格式下拉（保持原格式/JPG/PNG/WebP）、质量滑块（0.1–1.0，PNG 时禁用）、最长边缩放输入（可选，留空表示不缩放）
  - 文件列表区：每行显示缩略图小图、文件名、原始尺寸/体积 → 处理后体积、节省百分比、下载按钮
  - "全部处理"与"全部下载"按钮
- 引用同目录 `style.css` 与 `script.js`，无外部依赖。

### 2. `image-tool/style.css`

- 简洁卡片式布局，移动端可用（max-width 容器 + 弹性列表）。
- 风格与 `demo-showcase/style.css` 一致：浅色背景、圆角卡片、系统字体。

### 3. `image-tool/script.js`

核心逻辑（原生 JS，无框架）：

- **文件接入**：input change + dragover/drop 事件收集 File 对象，按文件类型白名单过滤，重复添加去重（按 name+size+lastModified）。
- **解码**：`createImageBitmap(file, { imageOrientation: 'from-image' })` 保留 EXIF 方向；解码失败时行内提示错误，不中断其他文件。
- **处理**（异步逐个执行，避免大图阻塞 UI）：
  1. 依据"最长边缩放"计算目标宽高（保持宽高比，不放大）；
  2. 绘制到 `OffscreenCanvas`（不支持则回退 `document.createElement('canvas')`）；转 JPG 时先用白色填充画布，避免 PNG 透明区域变黑；
  3. `canvas.convertToBlob`/`toBlob(mime, quality)` 输出：JPG/WebP 使用质量滑块，PNG 忽略质量；
  4. 目标为 WebP 前先做能力检测（`canvas.toDataURL('image/webp')` 前缀判断），不支持时禁用该选项并提示。
- **结果与下载**：用 `URL.createObjectURL(blob)` 生成下载链接（`<a download>`，文件名规则：`原名-压缩.扩展名`）；显示原始/处理后体积与节省百分比；处理前显示进度状态（"排队中/处理中/完成"）。
- **边界处理**：>5MB 大图正常走同一流程；某文件失败仅标记该行失败原因，不影响批量。

## Assumptions & Decisions

- 纯浏览器端处理，无服务器、无打包工具，双击 `index.html` 或经任意静态服务器均可运行。
- 功能范围按用户确认：仅压缩 + 格式转换（含基本的处理结果展示与下载）；不做内容审核、不做服务端存储。
- 文件列表中的小缩略图仅为呈现处理对象所必需的最小预览，不是独立的"预览画廊"功能。
- 遵循工作区规则：原生 JS、注释解释"为什么"、中文界面。

## Verification Steps

1. 在 `/workspace` 启动 `python3 -m http.server 8000`（或直接用文件协议打开），用 OpenPreview 打开 `image-tool/index.html`。
2. 拖入 `/workspace/.uploads/` 中的测试图，验证：
   - 3 张 webp、jpg/jpeg 可正常解码并出现在列表中；
   - >5MB 的 PNG（2480x3508）压缩耗时可控、结果体积明显减小、页面不卡死；
   - JPG 质量滑块 0.5 时体积显著下降；PNG→JPG 转换后透明区域为白色而非黑色；
   - WebP 输出在当前浏览器可用（不可用时选项被禁用并有提示）。
3. 单个下载与"全部下载"均能得到文件名正确、可正常打开的目标图片。
4. 混入一个非图片文件（如 demo-showcase/text/hello.txt），确认被过滤或行内提示失败，不影响其他文件处理。
